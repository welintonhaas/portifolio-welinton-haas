Um portfólio moderno e responsivo que apresenta a jornada profissional de Welinton Haas, Tech Lead especializado em desenvolvimento full stack e DevOps.

## ✨ Características

- **🎨 Design Moderno**: Interface limpa com gradientes azuis e animações suaves
- **📱 Responsivo**: Otimizado para desktop, tablet e mobile
- **⚡ Performance**: Construído com Nuxt 4 para máxima velocidade
- **🌟 Animações**: Background animado com ícones tecnológicos flutuantes
- **📧 Contato Funcional**: Sistema de contato integrado com fallbacks

## 🛠️ Tecnologias Utilizadas

- **Framework**: [Nuxt 4](https://nuxt.com/) (Vue 3)
- **Estilo**: CSS3 com gradientes e animações
- **Ícones**: SVG customizados e emojis
- **Tipografia**: Inter (Google Fonts)
- **Deploy**: Pronto para Vercel, Netlify ou servidor próprio

## 📁 Estrutura do Projeto

```
nuxt-app/
├── components/
│   ├── Portfolio.vue          # Componente principal do portfólio
│   ├── CodeBackground.vue     # Background animado com ícones
│   ├── AnimatedCursor.vue     # Cursor customizado (desktop)
│   └── WordHuntCounter.vue    # Componente legacy (não utilizado)
├── app.vue                    # Layout principal da aplicação
├── nuxt.config.ts            # Configuração do Nuxt
└── package.json              # Dependências do projeto
```

## 🚀 Como Executar

### Pré-requisitos
- Node.js 18+ 
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone [URL_DO_REPOSITORIO]

# Navegue até o diretório
cd nuxt-app

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:3000`

### Build para Produção

```bash
# Gerar build de produção
npm run build

# Pré-visualizar build
npm run preview
```
